# Light-pollution project lab notebook

This directory is the chronological research notebook for the European VIIRS
light-pollution project.

The notebook is intentionally broader than the final manuscript record. It
should preserve exploratory analyses, negative results, implementation choices,
failed modelling ideas, methodological concerns, and the reasoning behind
changes of direction.

The current restart point is also mirrored in [`docs/CURRENT_STATE.md`](../CURRENT_STATE.md) so a new session does not have to reconstruct the last terminal state from chat history.

## Convention

After a substantial project work session, add one dated Markdown entry containing
an opening summary, analyses performed, key numerical results, negative or
inconclusive results, code/commit references, methodological cautions, decisions,
and next-session priorities.

Entries should generally not be rewritten to make the history look cleaner than
it was. If an interpretation changes later, record that change in a new dated
entry and link back to the earlier note.
