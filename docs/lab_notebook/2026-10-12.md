## 1. Production calibration of the 2017 VIIRS discontinuity

### Question

Does the 2016-to-2017 brightness jump remain after restricting the analysis to pixels that are already retained as lit, and if so what correction form is supported?

### Retained-pixel test

Pipeline stage:

```bash
python src/run_pipeline.py annual-vnl-2017-pixel-test
```

The test used fixed NUTS2016 polygons and the 2015-2018 raw Annual VNL V2.2 `average_masked` rasters.

Two mechanisms were separated:

1. changes in positive-pixel support/masking;
2. changes in the radiance of pixels positive throughout 2015-2018.

For persistent positive pixels:

```text
excess_2017 =
    (R2017 - R2016)
    - 0.5 * [(R2016 - R2015) + (R2018 - R2017)]
```

### Result retained

The discontinuity remained on persistent lit support. It therefore cannot be explained simply by EOG's zero/background mask admitting a different set of pixels in 2017.

### Independent-brightness pass

Pipeline stage:

```bash
python src/run_pipeline.py annual-vnl-2017-correction-pass2
```

The first brightness stratification was recognized as partly circular because 2016 radiance both defined brightness and appeared in the transition contrast. Pass 2 therefore assigned pixels using an independent baseline:

```text
baseline brightness = mean(R2013, R2014)
```

The retained-pixel 2017 excess was approximately flat at **0.23-0.24 nW cm^-2 sr^-1** across the faint to moderate range. The empirical pass-2 estimate was **0.23478 nW cm^-2 sr^-1**.

### Segmented time-series pass

Pipeline stage:

```bash
python src/run_pipeline.py annual-vnl-2017-correction-pass3
```

The primary model was fitted over 2013-2019, excluding 2020 so that COVID-era effects could not determine the calibration step:

```text
R_t = a + b * (year - 2016) + delta * I(year >= 2017)
```

Additive and multiplicative forms were compared, along with candidate correction shapes.

### KEEP conclusion

Use the following production correction for every analysis country and territory from 2017 onward:

```text
raw <= 0 : corrected = raw
raw > 0  : corrected = max(raw - 0.235, 0)
```

This is a **pixel-level correction**, not a subtraction of 0.235 from a NUTS3 mean. It is applied before exact polygon aggregation.

### Important caveat retained

The additive behaviour is strongest in the dim-to-moderate radiance range. High-brightness pixels do not follow one perfectly constant offset. The production choice is therefore a pragmatic, empirically validated zero-point correction, not a claim that every bright pixel has an exactly identical sensor bias.

## 2. ISS/LED mechanism tests

Two new stages were built to test whether spectral whitening could contribute to the density dependence of historical VIIRS change:

```bash
python src/run_pipeline.py iss-led-switch-density-test
python src/run_pipeline.py iss-led-switch-annual-slopes
```

The mechanistic conversion uses the Sánchez de Miguel et al. relationship between ISS G/R and VIIRS response. Positive Δ(G/R), corresponding to spectral whitening, predicts a negative VIIRS-equivalent spectral component at equal green-band output.

The endpoint analysis showed substantial density-dependent whitening, but the direct endpoint regression evidence was weaker than the descriptive density pattern. The annual-slope analysis was therefore added to align the ISS mechanism more directly with the observed NUTS3 VIIRS slopes.

### KEEP interpretation

ISS spectral change remains a **mechanism test**, not a future technology trajectory and not a direct estimate of true lumen output. Equal-green normalization is not equivalent to constant lumens, electrical power, or biological exposure.

No future model should extrapolate the ISS spectral term indefinitely. If used in forecasting, it must enter as a bounded technology-state process.

## 3. Canonical future-radiance response framework

The future response pipeline was redesigned around a small set of pre-defined candidate models and a temporal holdout rather than selecting among many arbitrary formulas.

Relevant stage:

```bash
python src/run_pipeline.py future-radiance-response
```

The candidate set asks whether population-density change genuinely improves prediction beyond baseline population density. The holdout is temporally non-overlapping, and added complexity is retained only if it improves both inference and held-out prediction.

### KEEP methodological decision

If demographic-change terms do not pass the stopping rule, the canonical density response should come from the full longitudinal mixed model rather than from a five-year-pair model constructed only to test demographic-change terms.

The five fixed density-class values remain descriptive historical results; the continuous response is the transfer function for eventual projection.

## 6. First 2021 discontinuity diagnostic

Pipeline stage:

```bash
python src/run_pipeline.py future-radiance-2021-diagnostic
```

The first-difference analysis showed a large common disturbance:

```text
2020 -> 2021:
    corrected country-unbalanced regional median change: +10.033%
    78.5% of regions increased

2021 -> 2022:
    corrected regional median change: -8.345%
    12.15% of regions increased

country-balanced:
    2021: +18.9995%, 83.9% of countries positive
    2022: -10.861%, 3.23% of countries positive
```

Robust first-difference models supported a common 2021 pulse, a post-2021 shift, density structure, country structure and categorical-year behaviour beyond a simple breakpoint.

### KEEP conclusion

Do **not** summarize the complete 2014-2024 panel with one forced linear annual slope at this stage.

The 2021 increase is too large, too geographically widespread and too strongly reversed in 2022 to treat as an ordinary point on a linear trend. Its cause must be investigated before the future-response model is frozen.
