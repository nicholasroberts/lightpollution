## Decision to test a fully reconstructed density history (pending EcoVis run)

Investigator proposed **January-1 population count divided by the fixed NUTS3 land area**, rather than correcting only 2020 in the published annual average indicator. This has been implemented as a **separate, explicitly defined sensitivity dataset**, not as a production data replacement:

\`\`\`
python src/reconstruct_population_density_jan1_nuts2016.py --self-test
python src/reconstruct_population_density_jan1_nuts2016.py
\`\`\`

The script uses original Eurostat \`demo_r_pjanaggr3\` counts and \`reg_area3\` land area from the already-archived raw JSON files. It selects **2019 land area preferentially** (because the spatial analysis uses NUTS2016-era fixed polygons; fallback to 2018 or 2020 recorded explicitly), applies this **same region-specific denominator in every year 2014–2020**, never substitutes area from raw unprojected polygon geometry or total water-inclusive area, flags any region with >1% spread in 2018–2020 recorded land-area estimates, and omits any region missing a Jan-1 headcount in the required 7-year panel. It does not patch 2020 from the old density column or impute values.

It compares 2014→2019 and 2014→2020 population–PRC rank and threshold results using **exactly the same reconstructed and official-data regions**, reusing the established country-level analysis functions and untouched locked PRC series. It writes its own annual table, matched endpoints, country comparison, coverage/exclusion table, land-area provenance, and manifest to \`data/processed/nuts2016_jan1_population_density_sensitivity/\`; it **never overwrites** \`data/processed/nuts3_population_density.parquet\`.

**Known coverage warning:** initial 2019/2020 audit included Jan-1 counts for 1,285/1,317 regions and land area for 1,305/1,317. Missing Jan-1 records were BE 8, EE 2, HR 14, IT 8; absent land-area records were AL 12. Other years may further reduce complete panel; numbers from the pending reconstruction must be inspected before deciding whether that dataset should replace the original for inference. This stage has not yet run on EcoVis.

**Method caution:** Eurostat \`demo_r_d3dens\` is an *annual-average population / land area* metric; Jan-1 count / area is a **related but distinct measure**. Eurostat methodology: https://agridata.ec.europa.eu/Qlik_Downloads/InfoSheetSocioEconomic/infoC4.html. Changing source definitions changes coefficients/ranks even on identical spatial units. We should inspect area/NUTS coding, current-year population statuses, and spatial autocorrelation before significance claims. The 2021+ population series may use later NUTS boundaries and must not be silently appended to the frozen NUTS2016 panel.
