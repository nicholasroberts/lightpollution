### Implemented calculation

For equal included-pixel contributions, define r=10^-0.4, t=10^-0.04,
B=1-(r+t)/2 and A=(t-r)/2. A single eye response at axis theta is
B*I-A*(Q*cos(2theta)+U*sin(2theta)), matching recovered R par/perp at axes
0/90 degrees. Integrated maximum/minimum are

    M = B*sum(I)
    D = A*hypot(sum(Q),sum(U))
    Rmax = M+D; Rmin=M-D; PRC=ln((M+D)/(M-D))

The optimum is computed analytically, so a global polarization-pattern rotation
need not be manually corrected to obtain the maximum. Exposure co-registration
is a different operation and is NOT solved by maximizing contrast. A common
circular FOV and image-plane polarization reference are explicit conventions;
no unprovided curved-eye axis transport or spectral sensitivity is invented.
Intensity-mode summation uses equal pixel weights; an explicitly labelled
normalized-direction alternative is available if needed to test historical
normalization, not selected to improve site agreement.
